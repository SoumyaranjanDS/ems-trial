# Event Management System

A full-stack Event Management System built with Node.js, Express, MongoDB, and React (Vite).

## Features
- **User Authentication**: Role-based access control (Admin, Organizer, Attendee).
- **Event Discovery & Booking**: Browsing catalog, detailed event views, and ticket booking.
- **Organizer Dashboard**: Event creation, attendee tracking, QR code check-in scanning.
- **Admin Dashboard**: System administration and user/event management.

## Tech Stack
- **Frontend**: React (Vite), Redux Toolkit, Axios, Tailwind CSS / Custom Styling
- **Backend**: Node.js, Express, MongoDB (Mongoose)
- **Services**: Cloudinary, QR Code generation

## Getting Started

### Prerequisites
- Node.js (v18+)
- MongoDB database instance

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/SoumyaranjanDS/event-management-system.git
   ```

2. **Backend Setup**:
   ```bash
   cd server
   npm install
   npm run dev
   ```

3. **Frontend Setup**:
   ```bash
   cd client
   npm install
   npm run dev
   ```
